Book My Stay is a Java-based Hotel Booking Management System demonstrating OOP principles and core data structures. The project incrementally addresses real-world challenges such as room availability, inventory management, and fair booking request handling.

Key Features
1. Room Modeling
The system defines different room types—Single, Double, and Suite—each with attributes such as the number of beds, room size, and nightly price. This helps users understand the characteristics of each room before booking.

2. View Room Details and Pricing
Guests can access detailed information about each room, including bed count, room size in square feet, and price per night. This ensures transparency and allows informed decision-making.

3. Check Available Rooms
Users can see which rooms are currently available. The system displays only rooms with availability, preventing booking conflicts and providing an accurate inventory view.

4. Submit and Track Booking Requests
Guests can submit booking requests that are recorded in the order they are received. Requests are tracked to ensure fair and orderly processing, without changing room availability at the request stage.
